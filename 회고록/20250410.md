## 📌2217 로프 
### 풀이 과정 
- 임의의 로프 k개 중 **들어 올릴 수 있는 가장 작은 무게**에 k를 곱하면 된다. 
- `[10, 15]` 일 때 10, 15, (10,15) 각각에 대해 10, 15, 20이 최대중량이다.  

**풀이1. 시간 초과**
- 조합을 모두 구해 계산 시도했으나 시간 초과     
```python 
import sys
from itertools import combinations
input = sys.stdin.readline
N = int(input())
R = [int(input().rstrip()) for _ in range(N)]
res = 0 
for i in range(1,N+1):
    for g in combinations(R, i):
        # print(g)
        res = max(res, min(g)*len(g))
print(res)
```

**풀이2. 시간초과** 
R을 내림차순으로 정렬하고, tmp라는 임의 배열에 k개의 로프 중량을 저장해둔다. 그리고 가장 작은 값 tmp[-1]에 k를 곱하면 된다고 생각했다. 

그런데도 시간초과 발생 

이유를 생각해보니 인덱싱 및 max() 연산 때문인 것 같다. 
```python
import sys
input = sys.stdin.readline

N = int(input())
# 각 로프가 버틸 수 있는 최대 중량
R = [int(input().rstrip()) for _ in range(N)]
R.sort(reverse=True)
res = 0
# 로프들을 이용해 들어올릴 수 있는 물체의 최대 중량
for i in range(1, N+1):
    tmp = R[:i]
    res = max(res, tmp[-1]*len(tmp))
    print(res)
print(res)

```

**결론**
- 로프 k개를 사용한다고 하면 
- 내림차순 정렬한 배열 R에 대해 
- k-1의 인덱스 값에 k를 곱한 값 중 max값이 정답이다.

## 1269 대칭 차집합
A와 B 합집합에서 교집합을 뺀 원소의 개수를 구하는 문제

따라서, `len(a)+len(b) - (length of intersection)*2`

**다른 사람의 풀이** 
- for문으로 하나씩 모두 비교할 수도 있다. 
- **💡포인트: 딕셔너리에서 key in dic.keys() 연산의 시간 복잡도는 O(1)/ 리스트에서 in연산의 시간 복잡도는 O(n)이다.** 
```python
n,m = map(int, input().split())
a = {i:'' for i in input().split()}
b = input().split()
cnt=0
for i in range(m):
    if b[i] in a:
        cnt += 1

print(len(a)+len(b)-2*cnt)
```
