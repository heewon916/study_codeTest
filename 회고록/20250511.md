## 📌 1182. 부분 수열의 합
- 시간 초과풀이: 백트래킹으로, 각각의 수를 더하고 말고로 진행하지만, 중복 계산이 많아 시간초과가 발생한다. N이 20개인데,가능한 부분 수열의 개수는 2^N이므로, 모두 탐색한다면 2^20이 걸린다. 
- 💡 이미 계산한 부분이 어디인지 체크 -> res, idx 상태에 대한 중복 제거 
- 💡 매번 백트래킹 할 때마다 각 수에 대해 "선택", "미선택" 두 가지 경우 모두 고려 중 -> **재귀를 통해 부분적으로 탐색할 것**

```python
### 수정 전 코드 
def backtracking(idx, res):
    global count
    if res == S:
        count += 1
        return ## <- 문제점: 양수와 음수의 덧셈으로, 상쇄되는 부분수열이 존재할 수 있음. 이 경우를 놓침. 
    for i in range(idx+1, N):
        backtracking(i, res+li[i])
```

```python
### 수정 후 코드 
def backtracking(idx, res):
    global count
    if idx == N: 
        return 
    if res+li[idx] == S:
        count += 1
    backtracking(idx+1, res+li[idx])
    backtracking(idx+1, res)
```
