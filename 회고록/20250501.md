## 📌17413. 단어 뒤집기2
문자열 구현 문제이다.

복잡하게 경우가 느껴질 때 구조를 좀 더 확실히 세우는 것이 좋겠다. 내 풀이대로 풀면서, 구조를 미리 안 잡고 실행결과를 보면서 고쳤더니 내가 어떤 경우를 고려했고 안했고가 헷갈렸다. 

**풀이과정**
- `flag = True`인 경우, <> 안에 있는 문자열이므로, 그대로 출력하도록 한다. 
  - `>`를 만나면 flag = False로 바꾼다.
- `flag = False`인 경우, <> 밖에 있는 문자열이므로, 따로 tmp에 저장해둔다. 그리고 공백을 만나면 tmp[::-1]출력 후 tmp를 초기화한다. 
  - 이때 공백은 뒤집어지면 안되므로, tmp에 추가하지 않고 곧바로 출력한다. 

**다른 사람 풀이** 
훨씬 구조적이다.

`<open>tag<close>`를 예시로 들어보면,
- 구분자`<`로 split하면, `[open>tag, close>]`만 남는다. 
- 각 단어 안에 `>`가 있으면, 1번만 더 `>`로 split한다. `open>tag`의 경우 open, tag 각각이 tag, rest 변수에 저장된다. tag는 그대로, rest는 뒤집어 result에 각각 append한다. 
- 없다면, 일반 단어이므로 그대로 뒤집어서 result에 append한다. 

맨 만지막에 result의 값들을 모두 join해서 출력하면 된다. 

```python
def reverse_word(word):
    result = []
    split_by_tag = word.split('<')
    for n in split_by_tag:
        if '>' in n:
            tag, rest = n.split('>', 1)
            result.append(f'<{tag}>')
            reversed_rest = ' '.join([m[::-1] for m in rest.split()])
            result.append(reversed_rest)
        else:
            just_word = ' '.join([i[::-1] for i in n.split()])
            result.append(just_word)
            
    answer = ''.join(result)
    return answer
    
word = input()
print(reverse_word(word))
```

## 📌17626. four squares
### ❌풀이 오류.
n = 1부터 8까지 차례대로 계산해봤을 떄 1,2,3,1,2,3,4,2 의 결과값이 나온다. 

n = 8: 제곱수 합의 조합 중에서 최소 개수를 구할 때,
7 + 1
6 + 2 
5 + 3
4 + 4
위와 같이 1부터 4까지는 무조건 계산하게 된다.

따라서,
- 한 숫자에 대해서, 최소 개수를 구하려면 우선 가장 큰 제곱수부터 고려해야 한다고 생각했다. 그래서 n보다 작은 제곱수 중 가장 큰 제곱수를 포함하면 나머지 계산을 자동으로 따라올 것이라 생각했다.
- ‼️그러나, 하나의 제곱수만 고려하고 있다. dp[i]를 업데이트할 때 현재 값보다 작은 제곱수를 다 확인한 후 최소값을 구해야 한다. 
```python
dp[1] = 1
dp[2] = 2
if N < 3:
    print(dp[N])
else:
    for i in range(3, N+1):
        half = math.sqrt(i)
        if half == int(half):
            dp[i] = 1
        else:
            dp[i] = dp[int(half)**2] + dp[i-int(half)**2]
```
### ❌시간 초과풀이. 
모든 제곱수 간의 조합을 고려해야 한다면 아래 풀이를 기억해두면 좋을 것 같다. 
하지만, 제한시간이 0.5sec로, n번을 꽉 채워서 풀이하면 시간초과가 발생한다. 
```python
# 1부터 N까지의 dp 값을 구함
for i in range(1, N + 1):
    # j는 제곱수들을 찾기 위한 변수
    j = 1
    while j * j <= i:
        dp[i] = min(dp[i], dp[i-j*j] + 1)
        j += 1
```

### ⭕과거 풀이.
- 현재 값의 제곱근을 구하고, 제곱근을 제곱해서 n에서 빼준다. 그럼 n보다 작은 제곱수 중 가장 큰 제곱수가 빠질 것이다. (cnt + 1)
```python
n = int(input())
cnt = 0
while n>1:
    sq_n =  floor(sqrt(n))
    # print('sq_n', sq_n)
    n = n - sq_n**2
    # print('n', n)
    cnt += 1
print(cnt)
```

## 📌2075. N번째 큰 수  
### ❌메모리 초과 
- 배열 크기: 1500 * 1500 = 2250000 ~= 2.25 * 10^6
  - 원소 한 개 범위: -10^6 ~ 10^6 -> 차지공간: 8byte 
  - 이유: 4byte = 32bit = 2^6 ~= 10^3
  - 데이터 들어간 배열: 최악의 경우: 전부 8byte 소모 
  - ==> 2 * 10^6 * 8byte = 18 * 10^6 
- 메모리 제한: 12MB ~= 12 * 10^6
따라서, 전체 배열을 저장하면 안된다. 

```python
N = int(input())
arr = []
for _ in range(N):
    tmp = list(map(int, input().split()))
    for i in range(N):
        arr.append(tmp[i])
    del tmp

arr.sort(reverse=True)
print(arr[N-1])
```
