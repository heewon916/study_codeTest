## 1748. 수 이어쓰기 1 
여러 케이스에 대해 직접 계산해보면서 자릿수 계산의 규칙을 파악해야 한다. 

**예시1**
N = 119
1-9 -> 9 
10-99 -> (99-10+1) * 2 = 90 * 2
100 - 119 -> (119-100+1) * 3

**예시2**
N = 1119 
1-9 -> 9 
10-99 -> (99-10+1) * 2 = 90 * 2 
100 - 999 -> (999-100+1) * 3 = 900 * 3
1000 - 1119 -> (1119-1000+1) * 4 

- 위의 예시들을 봤을 때 N의 자릿수 = len(N) = k라면 
- i에 대해서, 0부터 k-1까지는 9*(10**i)*(i+1)이고 
- k에 대해서는 (N-(10**(k-1))+1)*k이다.

이러한 규칙을 코드로 구현할 수 있어야 했다. 

## 9613. GCD의 합 
주어진 수들에서, 가능한 모든 쌍의 GCD 값을 다 더해야 했다. 

삼중 for문을 돌려도 시간 복잡도는 문제가 없었으므로 패스하고 

gcd를 구현해서 각 쌍에 대해 실행하면 되었다. 

**gcd함수 다시 짚고 가기**
```python
def gcd(a,b):
    while b:
        a, b = b, a%b
    return a
```
