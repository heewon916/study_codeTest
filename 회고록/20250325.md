- `key = lambda x:x[1]`의 문제점은, x좌표가 정렬되지 않는다는 점이다. 입력된 순서대로 출력된다.

## 2563번. 색종이 
### ✨나의 첫번째 풀이: 겹치는 면적을 수학적 수식으로 계산해 전체에서 뺄셈 
아직도 어디서 틀린 코드인지 잘 모르겠다.. 
```python
# 실패... ㅠㅠㅠ 
pos = [] 
for i in range(int(input())):
    x, y = map(int, input().split())
    pos.append((x,y))
pos = sorted(pos, key=lambda x:(x[0], x[1]))

# 겹치는 영역
intersect = 0
for i in range(3):
    x1, y1 = pos[i]
    for j in range(i+1, 3):
        x2, y2 = pos[j]
        if (x1+10) <= x2 or (y1+10)<=y2 :
            continue # 안 겹침 
        else: 
            x_overlap = max(0, min(x1+10, x2+10)-max(x1,x2))
            y_overlap = max(0, min(y1+10, y2+10)-max(y1,y2))
            intersect += x_overlap * y_overlap
            # intersect += (x1+10-x2 if x1<x2 else x2+10-x1)*(y2+10-y1 if y1>y2 else y1+10-y2)
            # print("intersect = {}*{}".format((x1+10 - x2),(y2+10-y1 if y1>y2 else y1+10-y2)))
            # print("({},{}), ({},{}), {}".format(x1, y1, x2,y2, intersect))

print(100*3 - intersect)
```
