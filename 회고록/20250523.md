## ✨📌11055. 가장 큰 증가하는 부분 수열 
#### 시간초과풀이: 백트래킹 
```python
N = int(input())
li = list(map(int, input().split()))
max_sum = 0
def backtrack(i, sum):
    global max_sum
    max_sum = max(sum, max_sum)
    for k in range(i+1, N):
        if li[k] > li[i]:
            backtrack(k, sum+li[k])

for i in range(N):
    backtrack(i, li[i])
print(max_sum)
```

### ✨정답풀이: DP 
- dp[i]: arr[i]를 끝으로 하는 부분 수열에서 합의 MAX값 
- 초기상태: 최소한 자기 자신만 포함하니까, dp[i] = arr[i] 
- i에 대해서, j (0<=j<i)일 때 arr[j] < arr[i]이면 합에 포함. 
  - `dp[i] = 현재 값(arr[i]이자 dp[i]) v.s. 이전 값 포함(dp[j]+dp[i] 또는 dp[j]+arr[i])`

  - => dp[i] = (현재 길이 dp[i]) v.s. (나보다 큰 원소도 포함한 수열의 길이 dp[j] + 1) 

## 📌1699. 제곱수의 합 
### 틀린 풀이: 그리디 알고리즘 
- 예외케이스 발생: 12 = 9+1+1+1 = 4+4+4 
- 위의 케이스에서, 그리디는 전자를 택한다. 
```python
cnt = 0
while N > 0:
    power = int(math.sqrt(N))**2
    N -= power
    cnt += 1
print(cnt)
```

### ✨정답풀이: DP 
차례대로 1부터 결과값을 계산해보면, 
1 -> 1
2 -> 2
3 -> 3 
4 -> 1
5 -> 2
6 -> 3
7 -> 4
8 -> 2
9 -> 1 ...

- 예를 들어 7에 대해 살펴볼 때 
- 7 = 6 + 1 = 5 + 2 = 4 + 3 이렇게 조합이 있다. 
- 각각의 경우마다 몇 개의 제곱수가 필요로 되는지 살펴봐야 하기 때문에 
- for문 안에 while문으로 전부 살펴보는 것임!!!
