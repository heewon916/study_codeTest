## 📌✨✨14501. 퇴사 
#### 풀이1. 재귀함수
포인트: 
1. 상담 가능여부는 day에 달려있으므로, 매개변수로 day만 전달하여, 함수 초반에 상담 가능한지부터 체크한다. 
2. day+T <= N 일때만 상담이 가능하다. 이때 그날 상담을 하는 경우 take, 하지 않는 경우 skip로 계산하여 max값을 리턴받는다.
3. 만약 그날 상담이 불가능한 경우(day+T > N), 그 다음날로 넘어간다. 
```python
import sys
input = sys.stdin.readline
N = int(input().rstrip())
tp = [tuple((map(int,input().rstrip().split()))) for _ in range(N)]

def benefit(day):
    if day >= N: # day가 퇴사일보다 크거나 같으면 상담 불가능
        return 0
    T, P = tp[day]

    # day+T 했을 때 상담을 퇴사일 당일까지 완료할 수 있다면
    if day+T <= N:
        # ㅂ
        take = P + benefit(day+T)
        skip = benefit(day+1)
        return max(take, skip)
    else:
        return benefit(day+1)
print(benefit(0))
```
#### 풀이2. 재귀함수 + 백트래킹 
- 단, N이 15~20일때만 가능하다. 

포인트: 
1. 퇴사일과 같거나 넘기면, 전역변수로 선언한 max_profit을 갱신해준다. 
2. 만약 앞으로의 상담이 가능할 경우(day < N), 
   - 그날 상담을 할 수 있고 했을 때 (day+T<=N), day+T로 함수를 호출한다. 
   - 그날 상담을 하지 않는 경우, day+1로 함수를 호출한다.  
```python
import sys
input = sys.stdin.readline
N = int(input().rstrip())
tp = [tuple((map(int,input().rstrip().split()))) for _ in range(N)]

max_profit = 0
def backtrack(day, current_profit):
    global max_profit
    if day >= N: 
        max_profit = max(current_profit, max_profit)
        return 
    T, P = tp[day]
    # 상담 할 경우 
    if day+T <= N: 
        backtrack(day+T, current_profit+P)
    
    backtrack(day+1, current_profit)
backtrack(0, 0)
print(max_profit)
```
#### 풀이3. DP
✨이해하기 좀 힘들다.. 
```python
N = int(input())
T = []
P = []
for _ in range(N):
    t, p = map(int, input().split())
    T.append(t)
    P.append(p)

dp = [0] * (N + 1)  # N일까지 포함해서 dp 배열 만들기

for i in range(N - 1, -1, -1):
    if T[i] + i > N:
        dp[i] = dp[i + 1]
    else:
        dp[i] = max(P[i] + dp[i + T[i]], dp[i + 1])

print(dp[0])

```
#### N의 가동 범위 구하기 
백트래킹의 경우:
- 각 day마다 상담한다 vs. 안한다 -> 2가지 분기 

즉 최악의 경우에는 2^N가지의 선택을 탐색한다. 
- N = 10 -> 최대 2^10 (⭕가능)
- N = 20 -> 최대 2^20 (⭕가능)
- N = 30 -> 최대 2^30 ~= 10^10 > 10^8 * 2 (‼️NO)

이때 2초가 시간제한이 걸린다. 2초는 10^8(1억) * 2 = 2억 번의 연산이 가능하다.

> ‼️중요: **2^n ~= 10^(n/3.3)**

> 2. `2^20 ~= 10^6`
> 3. `2^30 ~= 10^9`

## 📌1021. 회전하는 큐
왼쪽에 가까운지, 오른쪽에 가까운지에 따라 연산을 수행한다.  
단, 이미 맨 앞에 위치한 경우에는 2,3번 연산 수행 없이 popleft()만 수행하면 된다. 
1. pop_pt <- 뽑아야 할 위치를 찾아 넣고
2. 왼쪽에 가까운지, 오른쪽에 가까운지에 따라서 2,3번 연산의 횟수를 구한다. 

**💡논리 오류:**
- 큐 길이가 6일 때: len(q) == 6
- pop_pt = 3이면 -> 큐의 정 가운데 이상이기 때문에, 뒤쪽(오른쪽)이 더 멀어. 
- 즉, pop_pt >= len(q)//2 는 왼쪽이 더 멀다 -> 오른쪽으로 회전해야 함. 
근데 이 조건은 왼쪽으로 돌리는 코드에 들어가 있으니까, 오류가 발생할 수 밖에 없다.

그리고, 각 조건문 안에서 마지막에 q.popleft()를 해줘야 하는데 하지 않았다.

이렇게 되면, 뽑아야 할 숫자가 맨 앞에 위치해 있는데, 그 다음 뽑을 숫자로 포인터가 넘어가니까 논리적 오류가 생긴다.
