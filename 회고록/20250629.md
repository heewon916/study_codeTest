## 📌9184. 신나는 함수 실행
- 문제 파악: 
```text
111
=> 011 + 001 + 010 - 000
011 => 1
001 => 1
010 => 1
000 => 1

222
=> 122 + 112 + 121 - 111

결국 dp 문제이다. 앞서 계산한 상황을 다시 계산하지 않도록 저장해야 한다.
이때 a,b,c를 딕셔너리로 묶어서 저장하면 편할 것 같다.
```
### 첫 풀이: 시간초과
재귀하는 부분을 축소해야 할 것 같은데 어떻게 하면 좋을지..
a,b,c의 모든 가짓수에 대한 결과값을 미리 계산해두는 경우, 시간이 어떻게 되는지 생각해보자. 
- 제한시간은 1초, 즉 10^8번의 연산까지 가능하다. 
- 그렇다면? -50부터 50까지 a,b,c의 경우의 수는 100**3 = 10*6이므로 충분히 가능하다.  
```python
dp = {(0,0,0): 1}
def w(a,b,c):
    if (a, b, c) in dp:
        return dp[(a, b, c)]
    elif 0 in (a, b, c):
        dp[(a, b, c)] = 1
        return 1
    elif a > 20 or b > 20 or c > 20:
        return w(20, 20, 20)
    elif a < b < c:
        return w(a, b, c-1) + w(a, b-1, c-1) - w(a, b-1, c)
    else:
        return w(a-1, b, c) + w(a-1, b-1, c) + w(a-1, b, c-1) - w(a-1, b-1, c-1)

while True:
    res = 0
    a, b, c = map(int, input().split())
    if (a,b,c) == (-1,-1,-1): break
    else:
        print(w(a,b,c))
```

### 두번째 풀이: 
2차 고비 발생: 
- dp를 먼저 모두 계산하려고 하는데, a,b,c를 -50부터 50까지 삼중 반복문으로 돌릴 경우 c만 먼저 20를 넘겨서 딕셔너리에 keyerror가 생긴다.
  - 이 문제의 원인: 의존성 순서를 고려해야 한다. 
  - 20 이상의 값들을 채우려면 우선 0부터 20 사이의 값들이 채워져 있어야 한다. 
해결책:
- 다시 생각을 해보면, 20 이상의 값들은 모두 w(20,20,20)으로 대체되고 있고 
- 0 이하의 값들은 모두 1로 대체되므로, 실질적으로 계산이 필요한 부분은 0부터 20 사이이다. 
- 따라서 굳이 전체 범위에 대해서 계산할 필요가 없다.

### 파이썬에서 `*`연산자
언패킹Unpacking 연산자:
- **이터러블 언패킹** 1) 함수 인자로 언패킹 2) 리스트/튜플 병합 3) print함수에서 언패킹 
```python
# 함수 인자로 언팩킹
def sum_all(a, b, c):
    return a + b + c

numbers = [1, 2, 3]
print(sum_all(*numbers))  # 1 2 3이 각각 a, b, c에 전달되어 6 출력

# 리스트/튜플 병합 (확장)
list1 = [1, 2]
list2 = [3, 4]
combined_list = [*list1, *list2]  # [1, 2, 3, 4]

# print 함수에서 언팩킹 (가장 흔하게 볼 수 있는 예시)
print(*numbers) # 1 2 3 출력 (각 요소를 개별 인자로 print에 전달)
  ```
- **할당 언패킹**: 여러 개의 변수에 값을 할당할 때 나머지 요소를 리스트로 묶는데 사용됨. 
```python 
first, *middle, last = [1, 2, 3, 4, 5]
print(first)   # 1
print(middle)  # [2, 3, 4]
print(last)    # 5
```

패킹 연산자 `*args`: 함수의 매개변수 앞에 `*`를 붙이면, 여러 개의 인자를 tuple로 묶어 받는다. 특히 인자의 개수가 가변적일 때 유용하다.
```python
def my_function(*args):
    print(type(args)) # <class 'tuple'>
    for arg in args:
        print(arg)

my_function(1, 2, 3)
my_function('hello', 'world')
```

### 집합 set은 list를 원소로 받아들일 수 없다.
집합: 
- 원소의 중복을 허용하지 않음
- 새로운 원소가 추가될 때마다 해당 원소의 해시값을 계산해서 이미 존재하는 해시값인지 빠르게 확인한다. 

그러나, 리스트`[]`는 변경 가능한 `mutable`한 객체이다. 리스트의 내용이 변경될 때마다, 해시값 또한 변경된다. 해시값이 변경되면 집합이 원소를 제대로 찾거나 중복을 확인할 수 없다. 따라서 파이썬은 변경 가능한 객체는 해싱할 수 없다고 규정한다.
