  - 선형합으로 해당 날짜가 최소공배수 내에서 어느 날짜에 해당하는지 계산한다. 

### 다른 풀이 2 
- E의 값은 연도%15, S의 값은 연도%28, M의 값은 연도%19한 값이다. 
  - 따라서 E가 작으면 E+15, S가 작으면 S+28, M이 작으면 M+19를 반복하여 E=S=M이 되도록해야 한다. 
- 결론: esm 각각에 대해서 같은 햇수를 가리킬 때까지 계산하기
  - `(15*e)+E = (28*s)+S = (19*m)+M`
```plain text
(E, S, M)
= (15, 2, 11) -> 30 = (E)15+**15** = (S)28+**2** = (M)19+**11**
= (12, 1, 19) -> 57 = (E)15+15+15+**12** = (S)28+28+**1** = (M)19+19+**19**
```

```python 
##구현
E, S, M = map(int, input().split())
year = 1

while True:
    if ((year-E) % 15 == 0) and ((year-S) % 28 == 0) and ((year-M) % 19 == 0):
        break 
    year += 1

print(year)
```

## 📌 11004번
**heapq모듈 시간복잡도 정리**
1. `heapq.heapify(l)` O(n)
2. `heapq.heappop(l)` O(logn)
3. `heapq.heappush(l, item)` O(logn)
4. `heapq.heapushpop(l, item)` O(logn)
   - 새로운 항목을 추가하고 동시에 가장 작은 값도 제거

**시간계산**
- 만약 1초에 1억(10^8)번의 연산을 처리할 수 있다면, 1개의 연산이 약 \( 10^{-8} \)초에 해당합니다.
- \( N = 5,000,000 \)이면, 연산 시간은 대략 \( 5,000,000 \times 10^{-8} \)초가 됩니다.

  \[
  \text{실행 시간} = 5,000,000 \times 10^{-8} = 0.05 \, \text{초}
  \]

따라서, **N = 5,000,000**일 때 **O(n)** 시간 복잡도를 가진 연산은 대략 **0.05초** 정도 걸릴 것으로 예상됩니다.
