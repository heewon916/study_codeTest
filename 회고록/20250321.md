### 📌2869번. 달팽이는 올라가고 싶다 
- 처음에는 while문으로 작성했는데, 시간 초과가 뜨는 걸 보고 계산 상의 규칙을 찾고자 했다. 
- 하루에 a만큼 올라갔다가 b만큼 떨어지는데, 마지막날 떨어지는 건 고려 안하니까 `v//(a-b)`로 게산하면 될 것이라 처음에 생각했다. 
- 그러나 하루에 `a-b`만큼 올라간다고 가정하지만, 실제 마지막 날에는 b만큼 미끄러질 필요가 없다. 따라서 `a-b`로 나누기 전에 `b`를 빼줘야 한다. 
- 따라서 `(v-b)/(a-b)`로 생각하게 된다. 이때 소수점이 발생하게 되면, 추가 요일이 필요하다는 뜻이므로, `math.ceil((v-b)/(a-b))`로 계산해주면 된다. 

* 예제 1
a = 2, b = 1, v = 5라고 하자. 
이때 v-b = 4, a-b = 1 이다. 즉 총 4일 걸리고 정답이다. 

* 예제 2
a = 5, b = 1, v = 6
v-b = 5, a-b = 4 -> `//`연산으로 1일 걸리지만, 실제 나눗셈 연산에 의하면 소수점이 존재하게 된다. 따라서 실질적으로는 2일이다. 

이렇게 소수점이 존재하는 경우를 위해서, `math.ceil`함수를 사용해주면 된다. 

---
반대로, `(v-b-1)//(a-b)`로 계산할 수도 있다. 

- `V - B - 1`: V-B보다 1 적은 값으로 계산하면 올림 효과 발생
- `// (A - B)`: 정수 나눗셈으로 나누고
- `+1`: 첫날은 무조건 올라가기 때문에 하루 추가
이 방법을 사용하면 소수점을 신경쓰지 않고도 올림 연산이 가능하다. 

### 📌10989번. 수 정렬하기3 
- 숫자를 전부 하나의 리스트에 넣고 sort() 함수를 사용할까 했는데 수의 개수를 보고 시간 초과가 분명 뜰거라는 생각이 들었다. 
- 그래서 힙트리 heapq모듈 + 중위순회를 할까 했는데, 트리 구현까지는 원하는 것 같지 않았다. 
- 버블/삽입/선택 정렬 모두 O(n^2), 퀵/병합/힙 정렬은 O(nlogn)이지만 메모리 초과가 발생할 수 밖에 없다.
- 검색해본 결과 알게 된 것 **"계수정렬"**

📎**계수정렬**
- 각 숫자의 갯수를 세어주는 방식이다
- 숫자의 범위가 제한적이고 큰 수의 데이터를 정렬해야 할 때 매우 효율적이다.
- dp와 비슷하다고 느꼈는데, 미리 저장공간을 만들어 각 숫자들을 인덱스로 취급하고, 숫자들이 input될 때 횟수를 세어준다.
- 그걸로 처음부터 for문을 한번씩만 돌리면 된다는 것.
```python
n = int(input())
count = [0] * 10001

for i in range(n):
    num = int(input())
    count[num] += 1

for i in range(1, 10001):
    if count[i] != 0: 
        for j in range(count[i]):
            print(i)
```

### 1934번. 최소공배수 
소인수 분해 후, 각 소인수가 최대 제곱을 가질 수 있도록 함. 

12 16 
12 = 2^2 x 3
16 = 2^4 
=> 최대 제곱으로 가야 함 

**유클리드 호제법**
`LCM(a,b)= a×b / GCD(a,b)`
두 수의 곱을 최대공약수로 나누는 것이다. 
따라서 소인수분해할 필요 없이, 최대공약수(GCD)만 구하면 최소공배수(LCM)는 쉽게 구할 수 있다. 

- GCD(최대공약수) 구하기
1. 유클리드 호제법 사용 → gcd(a, b) = gcd(b, a % b)
2. b == 0이 될 때까지 나눔
3. 시간복잡도: O(log N) (매우 빠름!)

- LCM(최소공배수) 계산
1. LCM(a, b) = (a * b) // GCD(a, b)
2. 나누기를 먼저 하면 오버플로우 방지 가능!
```python 
def gcd(a, b):  
   while b:
     a, b = b, a % b  # 유클리드 호제법
   return a  
def lcm(a, b):
   return (a * b) // gcd(a, b)  # 최소공배수 공식 적용
# 테스트
print(lcm(6, 10))  # 출력: 30
print(lcm(12, 15)) # 출력: 60
print(lcm(7, 5))   # 출력: 35
```

```python
import sys
input = sys.stdin.readline

def gcd(a, b):  
    while b:  
        a, b = b, a % b  # 유클리드 호제법
    return a  

for _ in range(int(input())):
    a, b = map(int, input().split())
    print(a * b // gcd(a, b))  # 최소공배수 계산
```

**🎯 이해하기 쉽게 예제 분석**
예제: a = 6, b = 10
1. GCD(6, 10) 구하기
gcd(6, 10) → gcd(10, 6)
gcd(10, 6) → gcd(6, 4)
gcd(6, 4) → gcd(4, 2)
gcd(4, 2) → gcd(2, 0)  → 결과: GCD = 2

1. LCM(6, 10) 계산
LCM(6, 10) = (6 × 10) ÷ 2 = 30
