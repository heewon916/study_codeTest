```python 
# 기다리는 시간을 최소로 만들어야 한다.
# 소요시간을 오름차순으로 해서, 소요시간이 짧은 시간이 앞으로 오도록 한다.
import sys
input = sys.stdin.readline

N = int(input())
li = list(map(int, input().split()))
li.sort()
if N > 1:
    res = [0]*len(li)
    res[0] = li[0]
    res[1] = li[0] + li[1]
    for i in range(1, N):
        res[i] = res[i-1] + li[i]
    print(sum(res))
else:
    print(li[0])
```
### 과거 풀이 
```python 
N = int(input())
d = {}
arr = list(map(int, input().split()))
for i in range(N):
    d[i+1] = arr[i]
d_sorted = dict(sorted(d.items(), key=lambda x:x[1]))
total = 0
wait = 0
for t in d_sorted.values():
    wait = wait + t
    total += wait
print(total)
```

## 📌1920번. 수 찾기 
### 정답 풀이: 교집합으로 연산
- 100,000 이중 반복 시키면 10^10으로 1초 넘어감.
- 단 한번의 반복문 안에서 해결해야 한다.
- 집합 연산 중, 교집합 연산은 O(n) 시간복잡도를 가진다. 따라서 배열M에 대해 배열A와 교집합 연산을 한다. 그러면 어느 수가 있고 없고를 체크할 수 있다. => O(n) 
- 배열M 각 원소에 대해서, 위의 교집합에 있는 수면 1, 없으면 0을 출력하는데 O(n)*알파 일 것이다. 다행히 이 시간이 제한을 넘지 않아서 통과했다. 

### ✨과거 풀이: 이진탐색 알고리즘, 투포인터 알고리즘 
이 알고리즘으로 푸는 것이 가장 중요하다.
왜냐하면 위의 알고리즘은 예외케이스 발생 시 안 될 수도 있음. 

이진탐색을 활용하면, O(NlogN) 시간 복잡도를 낼 수 있다. 

**이중 반복문을 돌려야 하는데, 시간 복잡도에 걸릴 경우 투 포인터 알고리즘은 필수적인 것 같다.**

```python 
import sys
n = int(sys.stdin.readline())
n_s = list(map(int, sys.stdin.readline().split()))
n_s.sort()
m = int(sys.stdin.readline())
m_s = list(map(int, sys.stdin.readline().split()))

for m in m_s:
    # print(binary(m, 0, n-1))
    low = 0
    high = n-1
    while low <= high:
        mid = (low + high) // 2
        if n_s[mid] == m:
            print(1)
            break
        elif n_s[mid] < m:
            low = mid + 1
        elif n_s[mid] > m:
            high = mid - 1
    else:
        print(0)
```
