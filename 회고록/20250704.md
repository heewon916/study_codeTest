백트래킹인 것 같아서 그렇게 풀었는데 시간초과가 걸렸다. 
DP와 백트래킹을 구분하는 지점은 누적을 함수 인자로 전달할 것인가 아닌가에 있는 듯하다.

### 첫 풀이: bfs + 백트래킹 -> 시간 초과 
- 잘못된 풀이: 백트래킹이 정상 작동하지 않음. 
```python
import sys
sys.setrecursionlimit(10**6)
dr = [1, 0, 1]
dc = [0, 1, 1]

N, M = map(int ,input().split())
graph = [list(map(int, input().split())) for _ in range(N)]
visited = [[0 for _ in range(M)] for _ in range(N)]
visited[0][0] = 1 # (1,1)에서 시작
max_res = 0
def bfs(r, c, res):
    global max_res
    visited[r][c] = 1 ### 제대로된 백트래킹이 안되고 있다. 
    for i in range(3):
        nr, nc = r + dr[i], c + dc[i]
        if 0<=nr<N and 0<=nc<M:
            if not visited[nr][nc]:
                bfs(nr, nc, res+graph[nr][nc])
                visited[nr][nc] = 0
    else:
        max_res = max(max_res, res)

bfs(0, 0, graph[0][0])
print(max_res)
```

하지만, 중복된 계산이 많고, 시간제한이 10^8인데,
bfs 탐색 기법에 있어서 시간복잡도는 O(V+E)로 계산한다. (정점 수 V, 간선 수 E)
이때 2차원 배열에서의 탐색 기법을 쓸 때 시간 복잡도는

### DP로 누적된 합 계산을 해야 한다. 
얼핏 보면, bfs/dfs로 풀 수 있을거라 생각했다. 
근데, 이 문제를 다시 살펴보면 탐색 알고리즘을 통해서 최단 경로를 알아내는 게 아니라 최댓값을 구하는 것이다. 

- bfs -> 간선의 가중치가 모두 같을 때 '최단' 경로를 구하는 경우 
- dp -> 부분 문제를 해결하는 것으로 더 큰 문제를 해결할 수 있을 때 (✅)

dp 방식에 따라서, 2가지 풀이가 가능하다.
### 1. top-down 방식 
- 현재 상태를 만들기 위해 가능했던 경우 수  
현재 밟고 있는 칸까지 어떻게 왔는지 경우 가짓수
-> (i-1, j-1), (i-1, j), (i, j-1)
`dp[i][j] = max(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]) + graph[i][j]` 

### 2. bottom-up 방식 
- 작은 것부터 해결해가면서 큰 문제를 해결함 
현재 밟고 있는 칸에서 뻗어갈 수 있는 칸의 경우 가짓수: 3개  
-> (i+1,j) (i, j+1) (i+1, j+1)

- i+1 < N and j < M
dp[i+1][j] = max(dp[i][j] + graph[i+1][j], dp[i+1][j])
- i < N and j+1 < M 
dp[i][j+1] = max(dp[i][j] + graph[i][j+1], dp[i][j+1])
- i+1 < N and j+1 < M 
dp[i+1][j+1] = max(dp[i][j] + graph[i+1][j+1], dp[i+1][j+1])

이때 각 경우에 대해서 범위 제한이 필요할 것이다.
