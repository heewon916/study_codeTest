```python 
import sys 
from itertools import permutations
input = sys.stdin.readline 

N = list(map(str, input().rstrip()))

maxN = 0
for i in permutations(N, len(N)):
    # print(i, int(''.join(i)))
    if int(''.join(i))%30 == 0:
        maxN = max(maxN, int(''.join(i)))
        
if maxN: print(maxN)
else: print(-1)
```

## 📌10852. 국영수
**✨딕셔너리 lambda식**
1. `sorted(dic, key=lambda x:x)`
   - dic은 dic.keys()이다. 즉, x는 key값을 순서대로 받아 오름차순 정렬한다. 
2. `sorted(dic.items(), key=lambda x:x[0])`
   - dic.items() == (키, 값)
   - x[0], 즉 키 값을 기준으로 정렬할 것이다.
   - **단, 값은 정렬 기준에 포함되지 않는다.** 
3. `sorted(dic.items(), key=lambda x:(x[0], -x[1]))`
   - dic.items() == (키, 값)
   - x[0]은 key값, x[1]은 value값이다. 두 값 모두 정렬 기준에 포함된다. 
   - **단, x[0]는 오름차순 정렬, x[1]은 `-x[1]`이므로 내림차순 정렬이다.** 
```python
## 예시 ## 
for x in dic.items():
    print(x, x[0], x[1])
# 1번째 출력: ('Junkyu', (50, 60, 100)) Junkyu (50, 60, 100)
dic = dict(sorted(dic.items(), key=lambda x:(-x[1][0], x[1][1], -x[1][2], x[0])))
```

## 2960. 에라토스테네스의 체
> 에라토스테네스의 체
> > 에라토스테네스의 체는 N보다 작거나 같은 모든 소수를 찾는 유명한 알고리즘이다. 이알고리즘은 다음과 같다. 
> > 1. 2부터 N까지 모든 정수를 적는다.
> > 2. 아직 지우지 않은 수 중 가장 작은 수를 찾는다. 이것을 P라고 하고, 이 수는 소수이다.
> > 3. P를 지우고, 아직 지우지 않은 P의 배수를 크기 순서대로 지운다.
> > 4. 아직 모든 수를 지우지 않았다면, 다시 2번 단계로 간다.

## 1244. 스위치 켜고 끄기 
문제를 천천히 이해하고 구현해야 했다. 

남자는 인덱싱할 때 스위치 번호를 사전에 -1하면 안된다. 3일 경우 -1을 먼저 하면 2가 되는데, 범위가 1~7일 때 3이면 3,6뿐이지만 2가 되면 2,4,6이 되어 틀리기 때문이다. 따라서 스위치 번호를 그대로 for 조건문에 사용하고, 인덱싱할 때만 -1을 해줘야 한다. 

여자는 반대로 먼저 스위치 번호-1을 해줘야 한다. 그렇지 않으면 한 쌍을 더 비교하게 되기 때문이다.
