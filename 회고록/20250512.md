## 📌1406. 에디터 
- 시간초과풀이: 
    - 커서가 맨 끝에 위치한다는 것 -> N-1이 아니라 N
    - B 명령에서 문자를 삭제할 때, `string[cursor] = ''`처럼 빈 문자열로 처리하기보다, pop(위치) 함수를 사용해 제거하는 방식이 안전하다. 
    - **문자를 삽입할 때, 현재 커서 위치에 그대로 문자를 삽입하고, `cursor += 1`을 해줘야 한다.**
    ```python
    for _ in range(M):
        cmd = input().rstrip()
        if cmd == "L":
            if cursor > 0:
                cursor -= 1
        elif cmd == "D":
            if cursor < len(string):
                cursor += 1
        elif cmd == "B":
            # if (cursor - 1) >= 0:
            #     cursor -= 1
            #     string[cursor] = ''
            if cursor > 0:
                cursor -= 1
                string.pop(cursor)
        else:
            cmd0, cmd1 = cmd.split()
            string.insert(cursor, cmd1)
            cursor += 1
    ```
- 해결방법: 양쪽 끝을 관리하는 두 큐를 활용 
  - left_q: 커서 왼쪽의 문자열 관리 (초기상태: 문자열 자체) 
  - right_q: 커서 오른쪽의 문자열 관리 
  - 커서가 왼쪽으로 이동:: left.pop(-1)해서 right에 insert(0)
  - 커서가 오른쪽으로 이동:: right.pop(0)해서 left에 append
