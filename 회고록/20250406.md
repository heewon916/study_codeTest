## 1158. 요세푸스 문제
- Queue 큐 응용 문제이다.
- K-1번 popleft-append를 반복하고, 마지막 K번째에서 popleft and 출력하면 된다. 
### 다른 사람의 풀이
- `*` 언패킹 연산자를 활용하는 것이 인상적이다.
- 배열A의 길이가 N으로 정해져 있어서 while문 대신 for문을 이용할 수도 있군  
- K번째에 해당하는 인덱스를 계산을 `(C+(K-1))%len(A)`로 했다. 해당 위치를 pop해서 따로 X에 저장해두고 마지막에 join하였는데 풀이가 훨씬 깔끔해 보여서 기록 !! 
```python
N, K = map(int, input().split())
A = [*range(1, N+1)]
X, C = [], 0
for i in range(N):
    C = (C+K-1) % len(A)
    X.append(str(A.pop(C)))
print('<', ', '.join(X), '>', sep='')
```
