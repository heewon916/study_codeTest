## 📌13909번. 창문닫기 
**기억해야 할 것**
숫자 N에 대해, N보다 작거나 같은 제곱수의 개수는 `int(math.sqrt(N))`의 값과 동일하다.

### 메모리 초과 풀이: 정석 풀이
전체 N개의 창문에 대해서 각 배수만큼씩 방문하며 열려있으면(1) 닫고(0), 그 반대의 경우도 처리한다. 

문제점
- 각 요소 정수 타입 int -> 4byte = 32bit 
- 필요한 배열의 크기 4 *(N+1) => 메모리 초과가 날 수밖에 없음. 
```python 
N = int(input())
windows = [0 for _ in range(N+1)]
for i in range(1, N+1):
    x = i
    while x <= N: 
        windows[x] = abs(windows[x]-1)
        x += i
    # print(i, windows)
print(sum(windows))
```

### 시간초과 풀이: 닫혀있는 창문 기준 카운트 
열려있는 걸 카운트하지 말고 닫혀있는 걸 카운트한다. 
- 1번째 사람에 의해 모든 창문은 열리게 되어있다. all windows open
- 2번째 사람부터 열고 닫는 걸 체크 
- 단, 모든 창문 확인 불가하므로 닫힌 창문 인덱스만 체크하자 
```python
N = int(input())

# open_w = 1 ~ 21...0 
# closed_w = 0
closed_w = []

#2번째 배수부터 
p = 2
while p <= N: 
    for i in range(1, N+1):
        if i%p == 0: 
            if i not in closed_w:
                closed_w.append(i)
            else: 
                closed_w.remove(i)
    p += 1
    # print(closed_w)
print(N-len(closed_w))
```
### 시간 초과 풀이: 규칙 찾기 
**규칙**
- 짝수번 방문한 곳은 결국 닫혀있고
- 홀수번 방문한 곳은 결국 열려있다
```plain text
10 => 3번
1: 12345678910
2:  2 4 6 8 10
3:   3  6  9  
4:    4   8   
5:     5    10
6:      6
7:       7
8:        8
9:         9
10:         10
-> 1001000010 (1,4,9)
```
**풀이**
```python 
import math 
N = int(input())
count = 0
for i in range(1,N+1):
    if math.sqrt(i) == int(math.sqrt(i)):
        count += 1
print(count)
```

### 정답 풀이: 규칙 찾기 
위의 규칙에서 한가지 더 발견해야 하는 것은

N에 대해서 열린 창문의 갯수는 

**N의 제곱근보다 작거나 같은 정수들의 제곱**이다. 

결국 `int(math.sqrt(N))`을 통해 그 값을 정수로 변환하면, 제곱수의 개수가 구해진다. 

따라서 아래처럼 풀이할 수 있다.

```python 
import math

# N 입력 받기
N = int(input())

# 제곱근을 구하고, 그 값까지의 정수 제곱수가 열려 있을 것입니다.
result = int(math.sqrt(N))

print(result)
```

## 📌9625번. BABBA
처음에는 규칙을 찾아야 한다는 생각을 못했다.
그래서 정직하게 A는 B로, B는 BA로 바꿔가며 문자열 추가해서 풀었더니 시간초과가 떴다ㅠㅠ.. 

아무리 생각해도 모르겠어서 검색을 해보니 규칙을 찾아 dp를 사용하는 문제라고 하길래 한번 규칙을 구해보니 아래와 같이 실제로 그랬다. 

A가 B보다 한발 늦은 피보나치 수열이다. 

따라서 K번째 피보나치 수열을 구하되, B 갯수는 dp[K]라면, A 갯수는 dp[K-1]이라는 것이다. 이를 유의해서 작성해야 한다. 

|횟수|A|B|
|-----|-----|-----|
|A|1|0|
|B|0|1|
|BA|1|1|
|BAB|1|2|
|BABBA|2|3|

### 정답 풀이
```python
# A, B, BA, BAB, BABBA, BABBABAB .
# 모든 B -> BA/ A -> B 
K = int(input())
dp = [0] * (K+2)
dp[0] = 0 
dp[1] = 1
for i in range(2,K+2):
    dp[i] = dp[i-1] + dp[i-2]
print(dp[K-1], dp[K])
```

### 시간초과 풀이 
```python
K = int(input())
s = 'A'
for _ in range(K):
    tmp = ''
    for i in s: 
        if i == 'A': tmp += 'B'
        elif i == "B": tmp += 'BA'
    s = tmp 
print(s.count('A'), s.count('B'))
```

## ✨1652번. 누울 자리를 찾아라 
### 틀린 풀이
하나의 행 안에 '..'가 들어있으면 된다고 생각했는데.. 이유 모르겠어요. 
```python 
import sys 
input = sys.stdin.readline
N = int(input())

graph = [input().rstrip() for _ in range(N)]
r, c = 0, 0

for row in graph: 
    if '..' in row: 
        r += 1

for row in list(zip(*graph)):
    if '..' in ''.join(row): 
        c += 1
print(r, c)
```

## 맞는 풀이: 라이브러리 최소화 
```python
import sys 
input = sys.stdin.readline
N = int(input())

graph = [list(map(str, input().rstrip())) for _ in range(N)]
r, c = 0, 0
for i in range(N):
    len_r, len_c = 0, 0
    for j in range(N): 
        if graph[i][j] == '.':
            len_r += 1
        else: 
            len_r = 0 
        if len_r == 2: 
            r += 1
        
        if graph[j][i] == '.':
            len_c += 1
        else: 
            len_c = 0
        if len_c == 2: 
            c += 1
print(r, c)
```
