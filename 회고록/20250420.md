## 11659. 구간 합 구하기 4 
**풀이1. 시간초과** 
```python
import sys
input = sys.stdin.readline

N, M = map(int, input().rstrip().split())
li = list(map(int, input().rstrip().split()))

for _ in range(M):
    i, j = map(int, input().rstrip().split())
    print(sum(li[i-1:j]))
```
