## 📌25192. 인사성 밝은 곰곰이
**틀린 풀이**
"ENTER"가 아닌데 이미 말한 사람이라면?
즉, str != "ENTER" 이고 str in dic일 때도 else로 들어가서 딕셔너리를 초기화해버린다. 😱
```python
import sys
input = sys.stdin.readline
N = int(input().strip())
cnt = 0
dic = {}
# enter가 쳐지면, 앞에서 말했던 사람이어도 +1
for _ in range(N):
    str = input().rstrip()
    if str != "ENTER" and str not in dic:
        dic[str] = True
        cnt += 1
    else:
        dic = {}
print(cnt)
```

예를 들어서, 아래와 같은 예시가 들어올 경우
```plaintext
7
ENTER
A
A
B
ENTER
B
C
```
- A (cnt += 1)
- A (이미 말했으니까 else로 들어감 → dic 초기화됨❗)
- B (cnt += 1) → A가 사라졌으니 다시 B가 처음처럼 됨결과적으로 중복 카운팅됨 😭

**결론** 
- enter일 경우, clear()해준다. 
- enter가 아닐 경우 
  - dic 안에 없는 이름이면 추가한다.



## ✨📌1057. 토너먼트
두 사람이 붙는 시점은 아래의 조건을 만족해야 한다. 
1. 둘의 번호가 짝수-홀수 순서이고 
2. 같은 그룹이어야 한다. 

예를 들어서:
- 1 vs 2 -> 1라운드에서 만난다
- 3 vs 4 -> 1라운드에서 만난다
- 2 vs 3 -> ❌1라운드에서 못 만난다

근데 이 라운드 번호는 아래 규칙에 의해 계속 바뀐다: 
- 참가자 1번: 다음 라운드에서 (1+1)//2 = 1
- 참가자 2번: 다음 라운드에서 (2+1)//2 = 1
- 참가자 3번: 다음 라운드에서 (3+1)//2 = 2
-> 같은 번호가 될 때 서로 만나는 지점이 된다. 

정리하면 결국: 
- 다음 라운드에 대해서 각 참가자가 가질 번호는 (a+1)//2이다. 
- 만나게 될 경우는 a == b가 같아질 경우이고, 
- 같아질 때까지 라운드를 세면 된다
