  - Recurrsion Error: 파이선의 재귀 호출 제한 때문에 생기는 문제이다. 
  - 이를 해결할 수 있는 방법은
    1. `import sys; sys.setrecurrsionlimit(10**6)` 
    2. 반복문 dfs로 변경; 스택 활용 
    3. bfs로도 해결 가능; 큐 활용 

## 1874. 스택 수열
- 문제 이해를 제대로 해야 했다. 주어진 수 n개를 스택에 push/pop하는 게 아니라, 1부터 n까지의 수를 스택에 push/pop하면서 주어진 수열을 만들 수 있는가를 묻는 문제였다. 
- 주어진 수열을 target으로 잡고, target의 인덱스는 idx 변수로 선언한다. 
- 스택에 1부터 push하되, `stack[-1] == target`를 만족할 때까지 pop() -> idx+=1 하여 그 다음 위치의 수에 대해 확인한다. 만약 만족하지 않으면 다시 스택에 push한다.

  - ```python
    for start in range(N):
        s_num = li[start]
        max_len = 1
        for end in range(start+1, N):

                max_len += 1
        res = max(res, max_len)
    ```

## 📌11724. 연결 요소의 개수 
- bfs를 활용해서 큐로 구현을 했는데, 시간 초과가 떴다. (아,, 왜 시간복잡도 계산 안하고 시작했지)
  - 시간 제한은 3초 ~= 3 * 10^8 
  - 정점 개수 최대 1000개, 간선 개수 최대 약 5*10^5이다. 
#### 시간 복잡도 계산과정 
```python
N, M = map(int, input().split())
### 그래프 구성: O(N)
graph = [[] for _ in range(N+1)]
### 간선 입력 받기: O(M)
for _ in range(M):
    u, v = map(int, input().split())
    # graph[u][v] = 1
    # graph[v][u] = 1
    graph[u].append(v)
    graph[v].append(u)

visited = [0] * (N+1)
### BFS: 큐에서 하나씩 꺼내서 인접 노드를 확인하고 방문하는 방식이므로 => O(N+M); 모든 노드를 한번씩 방문하고 + 모든 간선에 대해서 한번씩 접근 
def bfs(start):
    q = [start]
    visited[start] = 1
    while q:
        x = q.pop(0)
        for adj in graph[x]:
            if not visited[adj]:
                q.append(adj)
                visited[adj] = 1

count = 0
### 전체 탐색: bfs 최대 N번 호출; 
for i in range(1,N+1):
    if not visited[i]:
        count += 1
        bfs(i)

print(count)
```
- 따라서 전체 코드의 시간 복잡도는 `O(N+M)`이다 
- 단, 큐 연산에서 `pop(0)`은 `O(N)의 시간이 걸린다.` 첫번째 원소를 꺼낼 때마다 모든 나머지 원소를 이동시키기 때문. 
- 💡이를 해결하기 위해선, deque 모듈의 popleft()을 활용하자. 
- 💡추가적으로, 입력의 크기가 너무 커서 시간이 초과될 때도 존재하므로, sys.stdin.readline 활용하는 것을 잊지 말자
