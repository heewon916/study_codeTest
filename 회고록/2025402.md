## 번. 타일 장식물 
1, 1, 2, 3, 5, 8, ... 을 보면 피보나치 수열의 특성을 가지고 있다. 

따라서, fib 배열을 미리 선언하여 값들을 구해둔다. 이 방식이 가능한 이유는 N이 1부터 80까지로 연산 범위가 적기 때문이다.

그리고 둘레를 구하는 방법은, N에 대해서, `(fib[N]+fib[N-1])*2 + (fib[N-1]+fib[N-2])*2`의 성질을 갖는다. 

이때 주의해야 할 점은 N=1일 때는 위의 식이 성립하지 않는다. fib[-1]의 값을 구하게 되어 틀리게 되므로, else문으로 따로 빼서 구하도록 한다. 

## 📌2828번. 사과 담기 게임 

### ✨틀린 풀이. 왜일까요~ 
```python
# N: 스크린의 크기, M: 바구니의 크기  N>M
N, M = map(int, input().split())
J = int(input())
bkt = [1, M]
dist = 0
for _ in range(J):
    pos = int(input())
    while True:
        if bkt[0] <= pos <= bkt[1]:
            break
        elif pos < bkt[0]:
            dist += bkt[0]-pos
            bkt[0] -= bkt[0] - pos
            bkt[1] -= bkt[0] - pos
        elif pos > bkt[1]:
            dist += pos - bkt[1]
            bkt[0] += pos - bkt[1]
            bkt[1] += pos - bkt[1]
print(dist)
```

### 정답 풀이
모든 i, j에 대해 가능한 조합을 찾아보는 방법이다. 
이 방법을 쓸 때 시간 복잡도만 문제 없으면 이 방법이 완전 탐색 방법으로 가장 간단하다. 

다시금 상기되긴 하는데!!! **모든 문제를 풀 때는 완전 탐색으로 시작하자.** 
```python 
s = input()
res = ''
for i in range(1, len(s)-1):
    for j in range(i+1, len(s)):
        p1 = s[:i][::-1]
        p2 = s[i:j][::-1]
        p3 = s[j:][::-1]
        
        combined = p1 + p2 + p3 
        if len(res) == 0 or combined < res: 
            res = combined
print(res)
```
