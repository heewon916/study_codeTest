## 📌2512. 예산
처음 생각:
- 오름차순으로 정렬한 다음에, 최소값 = arr[0], 최대값 = arr[-1]로 둔다.
- 두 개를 더해 2로 나눈 mid 값으로 총액 계산해보고, 
- 총액보다 작으면 mid +1, 크면 mid-1을 하려고 했는데..
### 틀린 풀이. 잘못된 논리 풀이
- 위의 방식대로 하면 숫자가 엄청 커질 때 계산 횟수가 급증해서 시간초과가 뜰 것 같았다.
- 그래서 상한액을 N으로 나눠서 기준치를 구하고
- 기준치보다 작은 경우, 상한액에서 바로 빼고, 큰 경우 빼기를 멈춘다. 
- 남은 상한액을 남은 필요한 갯수만큼 나눠서 구했는데.. (예제 케이스만 맞춤 ㅎ)
=> 결국 처음 생각이 맞다는 것. 이때 최소값은 arr[0]이 아닌 0이어야 한다. 그 이유는, 정렬하지 않는다고 했을 때 arr[0]이 꼭 최솟값이라는 보장이 없기 때문임. 
```python
avg = M // N
arr.sort()
left = -1
idx = -1
for i in range(N):
    if arr[i] < avg:
        M -= arr[i]
    else:
        left = N-i
        idx = i
        break
if M//left > arr[idx]:
    res = arr[idx]
else:
    res = M // left
print(res)
```
