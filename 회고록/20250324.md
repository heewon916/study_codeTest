## 2025/03/24 회고록 
### 
`''.join()`함수 주의 
- 반드시 모든 요소가 문자열이어야 한다. 만약 요소에 문자열이 아닌 값(숫자 등)이 포함되면 `TypeError`가 발생하게 된다. 따라서 `map()`함수, `for문`을 사용해 문자로 바꿔줘야 한다. 


### 1032번. 명령 프롬프트 
여러 개의 이터러블 객체를 동시에 순회할 수 있는 방법으로 `zip()`함수가 있다. 
**zip()**
두 개 이상의 이터러블(리스트, 문자열 등)을 동시에 순회하면서 각각의 같은 인덱스에 해당하는 요소들을 튜플로 묶어 반환한다. 
기본적으로 zip()은 가장 짧은 길이에 맞춰서 동작하기 때문에 문자열의 길이가 다를 경우 일부 문자는 비교되지 않을 수 있다. 


```python 
str1 = "hello"
str2 = "hxllo"
result = zip(str1, str2)
print(list(result))
# [('h', 'h'), ('e', 'x'), ('l', 'l'), ('l', 'l'), ('o', 'o')]
```

이때 같은 문자를 갖고 있는지 확인하는 방법에는 3가지가 있다. 

1. zip() 
   ```python
   for c1, c2, c3 in zip(str1, str2, str3):
      if c1 == c2 == c3:
        print(f"모든 문자열에서 동일한 문자: {c1}")
      else:
        print(f"문자들 비교: {c1}, {c2}, {c3}")

   ```
2. zip(), all()  -> 문자들이 모두 일치하는지 확인 유용용 
   ```python
   is_equal = all(c1 == c2 == c3 for c1, c2, c3 in zip(str1, str2, str3))
   ```

3. 문자열의 개수를 모를 때 
- `*args`를 사용할 수 있다. 
---
**함수에서의 `*args`, for문에서의 `*args`**
1. 함수에서의 *args
   - 함수에 전달된 인자들을 튜플 형태로 받는다. 
   - *args가 아닌 `args`인 경우에는, 인자로 튜플/리스트를 전달해야 한다. `func(iterable)`
2. for문에서의 *args
   - 튜플 형태로 받은 문자열 묶음에서 같은 자리를 하나씩 분리한다. 
   - `zip(*args) == zip(str1, str2, str3...)`
```python
def compare_strings(*strings):
    for chars in zip(*strings):
        if all(c == chars[0] for c in chars):  # 모든 문자가 동일한지 확인
            print(f"모든 문자열에서 동일한 문자: {chars[0]}")
        else:
            print(f"문자들 비교: {', '.join(chars)}")
compare_strings(str1, str2, str3, str4)
```
---

예외적으로, 

각 문자열의 길이가 동일하지 않은 경우에는, `itertools.zip_longest()`를 사용하면 된다. 
```python
from itertools import zip_longest

def compare_strings(*strings):
    for chars in zip_longest(*strings, fillvalue=None):
        if all(c == chars[0] for c in chars if c is not None):
            print(f"모든 문자열에서 동일한 문자: {chars[0]}")
        else:
            print(f"문자들 비교: {', '.join([str(c) if c is not None else 'None' for c in chars])}")

# 사용 예시
str1 = "hello"
str2 = "hxllo"
str3 = "hallo"
str4 = "hx"

compare_strings(str1, str2, str3, str4)
```
