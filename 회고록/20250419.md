## 11726. 2xn 타일링 
이 문제 또한 n =1,2,3,4.. 직접 그려보면서 방법의 수 간의 규칙성을 파악하는 문제였다. 

그려보면, 1,2,3,5,..의 규칙성을 갖는 다는 걸 알게 된다. 이를 이용해 메모제이션 기법으로 풀어가면 된다. 

‼️단, 주의해야 할 점은 n = 1일 때는 dp[2]가 IndexError를 발생시킨다. 

따라서 항상 입력 범위를 다시 확인하고 예외 케이스에 대해 출력을 신경써야 한다.
