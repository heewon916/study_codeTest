## 9375. 패션왕 신해빈 
- 한번 입어본 조합은 절대 안 입는다는 것
- 같은 종류 중에서는 1가지만 착용 가능하다는 것 
- 어떤 종류는 아예 안 입을 수 있다는 것

따라서 예를 들어 3개의 종류가 있고, 각 종류에 a,b,c개의 선택지가 있다면 1) 한가지 종류만 입을 때, 2) 두가지 종류만 입을 때, 3) 세가지 종류 다 입을 때가 있게 된다. 

1)의 경우: a+b+c
2)의 경우: a*b + a*c + b*c
3)의 경우: a*b*c

위의 3가지 경우 모두를 더하는 것은, (a+1)*(b+1)*(c+1) = abc + ab + bc + ac + 1이다. 

따라서 위의 값에서 1을 빼주면 된다. 

## 2559. 수열
- N: 수열의 크기: 10^5 
- K: 연속할 길이: 10^5
- 제한시간 1초 이므로 이중반복문 불가

풀이과정:
- 처음 풀이: 연속할 범위의 인덱싱을 N-K번 max() 비교해 구하려 했다. 하지만 인덱싱 또한 O(N)이 걸린다. 따라서 최악의 경우 1초를 넘길 수 있다. 
- 해결한 풀이: 메모제이션 기법을 활용한다. 연속되게 K개씩 더한 값을 N-K개의 배열에 순차적으로 저장해간다. 

규칙성: 
- `dp[0] = li[0] + .. + li[K-1]`
- `dp[1] = li[1] + ... + li[K] = dp[0] + li[K] - li[0]`
이를 일반화하면,
- `dp[i] = dp[i-1] + li[i+K-1] - li[i-1]`

위의 점화식을 활용해서 풀이하면, 충분히 가능하다. 

메모리 공간은 최대 128MB ~= 128 * 10^6.
N-K+1개의 배열이 생기고, 각 수는 -100부터 100이므로 충분히 커버 가능하다.

## 15657. N과 M(8)
문제 해석: 
- 수열 내 숫자 중복 가능
- 같은 조합 중복 불가 (1,7) 있으면 (7,1) 불가

중요 코드: 
```python
def generate(start, chosen):
    if len(chosen) == M:
        print(' '.join(map(str, chosen)))
        return
    for i in range(start, N):
        chosen.append(li[i])
        generate(i, chosen)
        chosen.pop()

generate(0, [])
```

함수의 재귀 순서: li = [1,2,3]이라면
1. gen(0, [])
2. `i = 0`: gen(0, [1])
3. i = 0: gen(0, [1,1]) -> return -> chosen = [1]
4. i = 1: gen(1, [1,2]) -> return -> chosen = [1]
5. i = 2: gen(2, [1,3]) -> return -> chosen = [1] => go back to 2번 -> pop -> chosen = []
6. `i = 1`: gen(1, [2]) 
7. i = 1: gen(1, [2,2]) -> return -> chosen = [2]
8. i = 2: gen(2, [2,3]) -> return -> chosen = [2] => go back to 6번 -> pop -> chosen = [] 
9. `i = 2`: gen(2, [3])
10. i = 2: gen(2, [3,3]) -> return -> chosen = [3] => go back to 9번 -> pop -> chosen = []
11. 끝.
