```python
import sys
input = sys.stdin.readline

N = int(input())
li = [i for i in range(1, N+1)]

while len(li) > 1:
    li.pop(0)
    v = li.pop(0)
    li.append(v)
print(li[0])
```

## 📌1018번. 체스판 다시 칠하기 
### 풀이 과정 
**풀이1)**
- 문제점: 시작점 좌표를 변동해도 리스트 컨프리핸션에서 비교하고 있는 li[i]는 변화가 없으니 정확한 계산이 불가능함. 
```python
N, M = map(int, input().split())
li = []
for i in range(N):
    li.append(list(map(str, input())))

# 시작점 (0,0) ~ (N-7, M-7)까지 살펴봐야 함

whitestart = 'WBWBWBWB'
blackstart = 'BWBWBWBW'
res = []
for i in range(0, N-7):
    for j in range(0, M-7):
        # i, j; 8x8 크기의 맨 왼쪽 상단 시작점 좌표
        startW = 0; startB = 0
        for k in range(8): 
            if k%2 == 0:
                startW += sum([1 for a,b in zip(li[i], whitestart) if a !=b])
                startB += sum([1 for a,b in zip(li[i], blackstart) if a !=b])
            else:
                startW += sum([1 for a,b in zip(li[i], blackstart) if a !=b])
                startB += sum([1 for a,b in zip(li[i], whitestart) if a !=b])
        res.append(min(startW, startB))
print(res, min(res))
```

---
### ✨결론 
따라서, 시작점 (i,j)에 대해 이중 반복문을 돌린다. 

**k,l에 대해서 li의 (i+k, j+l)에 있는 값을 아래 2가지 경우에 대해서 계산해야 한다.** 

1. 맨 좌측 상단이 흰색으로 시작하는 경우(짝수행: start with White, 홀수행: start with Black)
   - k+l의 합이 짝수이면 W, 홀수이면 B이어야 한다. 
2. 맨 좌측 상단이 검은색으로 시작하는 경우(짝수행: start with Black, 홀수행: start with White) 
   - k+l의 합이 홀수이면 W, 짝수이면 B이어야 한다. 

**이때 `(k+l)%2==0`이라는 조건이 필요한데,** 

둘다 짝수일 때만 짝수 값이 나올 수 있으며 하나라도 홀수이면 홀수 값이 나오는 성질을 사용한다.

즉, 1번의 경우라고 예시를 들어보면 k,l에 대해서 
- k+l이 짝수이면 W이고 홀수이면 B이다. 이 규칙을 사용하는 것이다. 

| k | l | 값 |
|---|---| --- |
| 0 | 0 |  W  |
| 0 | 1 |  B  |
| 0 | 2 |  W  |
| 0 | 3 |  B  |
| 0 | 4 |  W  |
| 0 | 5 |  B  |
| 0 | 6 |  W  |
| 0 | 7 |  B  |
| 1 | 0 |  B  |
| 1 | 1 |  W  |
| 1 | 2 |  B  |
| 1 | 3 |  W  |

> 이 문제에서 기억하면 좋을 것은, 
> 1. 완전 탐색이 모든 PS의 시작이다. 
> 2. (k,l)에 대해 (k+l)%2 연산은 체스판 무늬로 각 위치를 가려낼 수 있다.
