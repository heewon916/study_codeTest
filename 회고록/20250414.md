## 📌9372. 상근이의 여행

우선 **가장 적은 종류**의 비행기를 타고 **모든 국가를 여행해야** 한다고 나와있다. 그리고 주어진 입력에 따르면 **(a,b) 쌍은 a-b를 왕복하는 비행기**가 있다고 한다. 

이를 해석하면 아래와 같다. 
1. 양방향 그래프이다. 
2. 연결 그래프가 보장된다. (모든 국가를 방문 가능)
3. 전체를 방문하는 최단경로를 찾아야 한다. 

따라서 bfs 방법을 떠올렸었다. 
- 큐를 사용하며 pop(0) 반복
- visited 조절을 해야 한다. 

**✨주의해야 했던 점**
- 간선의 수를 구하는 것이다. 노드의 수가 아님. 따라서 length를 구할 때 `length+=1`의 위치가 중요하다.

**다른 풀이**
근데, 위의 해석에 따르면 최소한의 비행기를 타서 모든 국가를 방문해야 하고, 연결 그래프가 보장된다면 최소신장트리에서의 간선 수를 묻는 문제와 같다는 것이다. 따라서 최소 신장 트리에서 필요한 간선 수 = N-1이므로 정답은 항상 N-1이다.

## 1120. 문자열 
- A의 위치를 이동하면서 최소 차이가 나는 곳에 위치시키고 빈 자리에 채워지는 문자는 B와 무조건 똑같이 하면 된다. 
- 결국 기존의 A와 B의 최소 차이를 알아야 한다.

✨서로 다른 길이의 문자열 간에 다른 문자 개수를 셈해볼 때 아래의 방식을 이용하면 좋다.
- 시작점의 위치를 i로 조정한다. 범위는 0부터 len(str2)-len(str1)까지 
- 각 위치에 대해서 tmp라는 부분 문자열을 만들고 
- zip()으로 각 위치에 해당하는 문자들을 비교한다.  
```python
# 길이: str1 <= str2 항상
for i in range(0, len(str2)-len(str1)+1, 1):
    tmp = str2[i:i+len(str1)]
    cnt = 0
    for a,b in zip(str1, tmp):
        if a != b: cnt += 1
    min_diff = min(min_diff, cnt)
```

## 📌2485. 가로수
주어진 나무 위치들에 대해서, 각 나무 간의 간격들을 모두 구하고, 그 간격들 간의 최대공약수가 결국 최종 나무 간격이 된다. 

**풀이1. 틀림 & 메모리 초과**
틀린 이유와 해결책 
1. dist; 각 나무 간의 간격을 구할 때, 중복 값은 제외하려고 했다. 
   - 예외 케이스:`[1,4,7,10]`과 같이 차이가 전부 3이면 `dist = [3]`이다. 이렇게 되면 max_gcd를 구하는 for문의 범위가 `0-1 = -1`이 되어 max_gcd = 0이 된다. 
   - 따라서 중복 값도 넣어줘야 한다. 
2. max_gcd; gcd는 결국 모든 간격 간의 최대공약수가 된다. 그래서 max값을 구하려고 했었다. 하지만 max 연산은 크게 의미가 없는데, gcd 자체가 최대공약수를 구하는 과정이기 때문이다. 따라서 모든 간격에 대해 전부 gcd()만 실행해주면 그것이 최대공약수이다.  
3. li2 선언문; 최종적으로 나무가 심어져야 하는 모든 위치를 담는 배열이다. 하지만 메모리 초과가 발생한다. 
   - 만약 max_gcd = 1이고, li[-1] = 10^9 = 10억이라면 li2는 int형 배열이므로 4byte * 10억 = 약 4GB를 차지한다. 따라서 메모리 초과가 발생할 수밖에없다.
   - 해결책; li2를 만들지 않고 총 필요한 나무의 개수를 구해야 한다. 
     - 마지막 위치 li[-1]과 첫 위치 li[0]의 차이를 구해 최종 나무 간격 gcd 값으로 나눠준다. 그 뒤 +1한다. 이 값에 처음에 주어진 N을 빼주면 그것이 정답이 된다.  
```python
# 가로수들이 모두 같은 간격이 되도록
# 가능한 적은 수의 나무
import sys
input = sys.stdin.readline

N = int(input().rstrip())
li = [int(input().rstrip()) for _ in range(N)]
def gcd(a, b):
    while b:
        a, b = b, a%b
    return a
dist = []
for i in range(N-1):
    d = abs(li[i]-li[i+1])
    if d not in dist:
        dist.append(d)
max_gcd = 0
for i in range(len(dist)-1):
    max_gcd = max(max_gcd, gcd(dist[i], dist[i+1]))
li2 = [i for i in range(li[0], li[-1]+1, max_gcd)]

print(len(li2) - len(set(li2).intersection(set(li))))
```
