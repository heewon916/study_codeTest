# 📌순열과 조합 
**공통점**
- 서로 다른 n개의 값에서 r개를 뽑아 나열하는 것

**차이점**
- 순열: 순서 고려함. nPr = n! / (n-r)!
- 조합: 순서 고려하지 않음. nCr = n! / (n-r)!r!

## 구현1. 재귀함수 
### 순열
- 배열 arr에 대해 r개씩 뽑아 순열을 만든다. 
```python
def permutation(arr, r):
    #1. used: i번째 값을 사용했는지 저장에 사용함. (중복 제거하기 위해)
    arr = sorted(arr) 
    used = [0 for _ in range(len(arr))]
    def generate(chosen, used):
        #2. 만약 chosen의 개수가 r이 되는 순간 하나의 순열이 만들어진 것이므로 출력 후 종료 
        if len(chosen) == arr:
            print(chosen)
            return 
        #3. 모든 순열은 arr[:] 값으로 시작되기 때문에, for문으로 모두 만들어야 한다. 
        for i in range(len(arr)):
            if not used[i]:
                chosen.append(arr[i])
                used[i] = 1
                generate(chosen, used)
                #4. 만약 return 안되면 취소 
                used[i] = 0 
                chosen.pop()
    generate([], used) 
```
### 조합
```python 
def combination(arr, r):
    # 1. 배열 정렬 
    arr.sort()
    
    def generate(chosen):
        # 2. 만들어진 순열이 r개가 되면 하나가 생긴거니 리턴 
        if len(chosen) == r: 
            print(chosen)
            return 
        # 3. 시작지점: chosen에 저장된 마지막 값 다음 -> 순서 고려X; 포함만 되면 되므로. 만약 빈 리스트면 인덱스 0부터
        start = arr.index(chosen[-1]) + 1 if chosen else 0 
        for nxt in range(start, len(arr)):
            chosen.append(arr[nxt])
            generate(chosen)
            # 백트래킹 
            chosen.pop()
    generate([])
```
### 조합 + 중복 가능 
```python
# 1부터 N까지의 수; M개 선택; 중복 가능 + 순서 무관; 
def combination(arr, r):
    arr.sort()
    def generate(start, chosen):
        if len(chosen) == r:
            print(chosen, start)
            return
        for i in range(start, N+1):
            chosen.append(i)
            print("gen {}, {}".format(i, chosen))
            generate(i, chosen)
            chosen.pop()
    generate(1, [])
combination([x for x in range(1, N+1)], M)
```
